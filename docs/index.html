Features

Everything you need. Nothing you don't.

Null Dark
Near-black backgrounds with a single Signal Blue accent. Designed for long sessions.
Smart Commits
Generate a conventional commit message from your staged diff with one keystroke.
Icon Pack
Custom file and folder icons for every language and framework, built in.
Terminal Command
null . opens any folder from any terminal. Added to PATH on install.
Context Menu
Native Win11 IExplorerCommand — "Open in Null" on every file and folder, no registry hacks.
Enhanced Markdown
GFM, Mermaid diagrams, KaTeX math, and GitHub Alerts — rich preview built in.
Ollama
Inline AI chat and code review with local models. No API key. Runs entirely on your machine.
