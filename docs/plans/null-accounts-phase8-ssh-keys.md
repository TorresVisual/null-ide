# Null Accounts — Phase 8: SSH Keys Implementation Plan

> **For agentic workers:** See Execution Options below — the checked Execution Mode box names the REQUIRED SUB-SKILL (superpowers:executing-plans or superpowers:subagent-driven-development).

**Goal:** From the Accounts panel a user can create an SSH key for an account, see its fingerprint, put its public key on GitHub/GitLab, test it, sign commits with it, and detach or delete it — and every repo bound to the account then pushes and (optionally) signs with that key.

**Architecture:** Same split as Phases 1–7: logic lives in modules that never import `vscode` at runtime and take side effects as injected dependencies. `tool.ts` is the one place a non-git process (`ssh-keygen`) is spawned; `sshKey.ts` is pure naming/parsing; `sshKeyOps.ts` runs `ssh-keygen` (create, fingerprint, signing test) and deletes managed keys; `keyUpload.ts` talks to GitHub/GitLab; `ui/keyActions.ts` orchestrates the user-visible actions through an injected `KeyUi`. The Phase 6 model grows two fields (`sshKeyPath` on any account, `signCommits`), `gitPlan.ts` turns them into repo-local config, and `GitWiring` applies it unchanged. Only `extension.ts`, `ui/keyUi.ts` and `ui/accountPicker.ts` touch `vscode` for this feature.

**Tech Stack:** TypeScript (strict), `node:child_process` `execFile` (`ssh-keygen`, `ssh`), global `fetch`, `node --test` + `node:assert`, the real `ssh-keygen` and `git` in unit tests (skipped if `ssh-keygen` is missing), Mocha via `@vscode/test-electron` for the integration spec.

**Spec:** `docs/specs/null-accounts-ssh-keys-design.md` (extends `docs/specs/null-accounts-design.md`, issue #102). This is plan 8: (1)–(5) landed, (6) Git wiring and (7) Integration are in `docs/plans/null-accounts-phase{6,7}-*.md`. **Phase 6 Tasks 1–6 must be in the tree first** — this plan edits `gitPlan.ts`, `gitWiring.ts`, `sshAccount.ts`, `sshCheck.ts` and `ui/accountPicker.ts` as Phase 6 leaves them. Phase 7 is independent; its test-only commands (`null-accounts.test.addAccount` / `removeAccount`) are used by Task 8.

## Global Constraints

- Phase 1–7 constraints still hold: every `.ts` file starts with `'use strict';`; unit-tested modules do not import `vscode` at runtime (`import type` is fine); secrets only in `SecretStorage` and never logged; edit TypeScript sources only — `extensions/null-accounts/out/` is tracked but regenerated by `npm run compile` and committed alone in a `chore: refresh null-accounts compiled output` commit (Task 8); commit after each task, message ends with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; do not push.
- Run tests with `npm --prefix extensions/null-accounts test` (runs `tsc`, then `node --test` over the files in `scripts.test`; a new test file must be appended to that list in the task that creates it). One file: `cd extensions/null-accounts && npx tsc -p tsconfig.json && node --test out/<file>.test.js`. Integration: `/verify-local null-accounts`.
- **No shell, ever.** Every process is `execFile` with an argv array; paths and passphrase-less `-N ''` are separate elements. The only value a shell sees is `core.sshCommand`, which Phase 6 already single-quotes.
- **The extension never reads a private key.** Only `ssh-keygen`, `ssh` and `git` do. The public key is read from `<key>.pub`.
- **Only keys inside `~/.ssh/null-accounts/` are ever deleted.** Anything else is detached (the setting is cleared, the file stays).
- **A token is only ever an `Authorization` header** to the account's own host. It is never in a URL, a message, a log line or a thrown error.
- Generated keys are ed25519 **without a passphrase** (a passphrase on argv is visible to other processes, and git cannot prompt inside the editor). Spec: "Non-goals".
- Key paths are stored as chosen/returned; `expandKeyPath` (Phase 6) is the single place `~/` and separators are normalised. `sshKeyOps.ts` functions take an **already expanded** key file; callers expand with `sshKeyFile(account, home)`.
- **Deviation from Phase 6** (applied to Phase 6's docs in Task 8): `sshKeyPath` is no longer ssh-only. `validateNewAccount` keeps it on any account (it used to drop it), `planFor` writes `core.sshCommand` for any account with a key and still writes the credential entry for token accounts, and `GitWiring` skips on a missing key file only for `authMethod: 'ssh'` accounts.
- Not in this phase: ssh-agent / passphrase support, `allowed_signers`, listing or revoking keys on the server, hardware keys, tag signing, switching a remote's URL scheme, and a palette command for any of this (the panel is the entry point).

## Review Focus

Inputs the spec implies but doesn't spell out, most likely to bite first. Each has a test in the owning task, or for editor-UI behaviour a check in Task 9.

1. **A key with a passphrase** (the user's own `id_ed25519`) — signing must be refused when switched on, with the reason, not fail every commit afterwards. (Tasks 2, 5)
2. **Delete pointed at the user's own key** — `~/.ssh/id_ed25519`, or a path that climbs out of the managed folder with `..`: never deleted. (Tasks 1, 2, 5)
3. **A repo with a hand-set `commit.gpgsign=false`** — unbinding (or turning signing off) puts it back; and a token account whose key file vanished still gets its identity and credential. (Task 3)
4. **Uploading a key the server already has**, or uploading twice — "already added" is a success, not an error; a signing-key failure after a successful upload says exactly that. (Task 4)
5. **Replacing the key on an account that signs** — signing switches off (the new key is not a signing key on the server yet), and the old key file is left on disk. An SSH-only account cannot have its key removed. (Task 5)

```ts
'use strict';

import { execFile } from 'node:child_process';

export interface ToolResult { code: number; stdout: string; stderr: string }

/** `ToolResult.code` when the program could not run at all: not installed, killed by the timeout, or not startable. */
export const TOOL_UNAVAILABLE = -1;

export interface ToolOptions { env?: NodeJS.ProcessEnv; timeoutMs?: number }

/** Runs `command args…`. Never rejects. */
export type RunTool = (command: string, args: string[], options?: ToolOptions) => Promise<ToolResult>;

export const runTool: RunTool = (command, args, options = {}) => new Promise(resolve => {
  const child = execFile(
    command,
    args,
    { env: { ...process.env, ...options.env }, timeout: options.timeoutMs ?? 15_000, windowsHide: true },
    (err, stdout, stderr) => {
      if (!err) { resolve({ code: 0, stdout, stderr }); return; }
      // A non-zero exit has a numeric `code`; a failure to start has a string one ('ENOENT') or none.
      const code = (err as { code?: unknown }).code;
      resolve({ code: typeof code === 'number' ? code : TOOL_UNAVAILABLE, stdout, stderr: stderr || err.message });
    },
  );
  // Nothing will ever answer a prompt: end stdin so a tool that reads it stops waiting.
  child.stdin?.on('error', () => { /* the tool exited before reading; its exit code says what happened */ });
  child.stdin?.end();
});
```

```ts
'use strict';

import path from 'node:path';
import { expandKeyPath } from './gitPlan';

/** Where Null IDE puts the keys it creates. Only files in here are ever deleted. */
export const managedKeyDir = (home: string): string => path.join(home, '.ssh', 'null-accounts');

/** "git.example.org:8443" + "Ada Lovelace" -> "git.example.org_8443_ada_lovelace": one safe file name on every OS. */
export function keyFileName(host: string, username: string): string {
  return `${host}_${username}`.toLowerCase().replace(/[^a-z0-9._-]+/g, '_').replace(/^\.+/, '');
}

/** `<dir>/<base>_ed25519`, or `<base>_2_ed25519`, `_3_`… — never a name where a key or its .pub already is. */
export function uniqueKeyPath(dir: string, baseName: string, exists: (file: string) => boolean): string {
  for (let n = 1; ; n++) {
    const file = path.join(dir, n === 1 ? `${baseName}_ed25519` : `${baseName}_${n}_ed25519`);
    if (!exists(file) && !exists(`${file}.pub`)) { return file; }
  }
}

/** `ssh-keygen` arguments for a passphrase-less ed25519 key. An argv: nothing here is parsed by a shell. */
export const keygenArgs = (file: string, comment: string): string[] =>
  ['-t', 'ed25519', '-f', file, '-N', '', '-C', comment, '-q'];

export const publicKeyFile = (keyFile: string): string => `${keyFile}.pub`;

export interface PublicKey { type: string; blob: string; comment: string; line: string }

const PUBLIC_KEY = /^(ssh-ed25519|ssh-rsa|ecdsa-sha2-nistp(?:256|384|521)|sk-ssh-ed25519@openssh\.com|sk-ecdsa-sha2-nistp256@openssh\.com) ([A-Za-z0-9+/]+={0,3})(?: (.*))?$/;

/** The first line of a `.pub` file. Refuses a private key outright, so a wrong file can never be uploaded or copied. */
export function parsePublicKey(text: string): PublicKey {
  if (/PRIVATE KEY/.test(text)) {
    throw new Error('That is a private key. Only the public key (.pub) is ever copied or uploaded.');
  }
  const line = text.split(/\r?\n/).map(l => l.trim()).find(Boolean) ?? '';
  const match = PUBLIC_KEY.exec(line);
  if (!match) { throw new Error('That file is not a public key.'); }
  return { type: match[1], blob: match[2], comment: match[3] ?? '', line };
}

/** "256 SHA256:abc… comment (ED25519)" -> "SHA256:abc…". */
export function parseFingerprint(output: string): string | undefined {
  return /\bSHA256:[A-Za-z0-9+/]+/.exec(output)?.[0];
}

/** The name the key gets on the server. */
export const keyTitle = (hostname: string, date: Date): string =>
  `Null IDE on ${hostname} (${date.toISOString().slice(0, 10)})`;

/** True only for a file strictly inside the managed folder. Resolves first, so `..` cannot climb out. */
export function isManagedKey(keyFile: string, home: string): boolean {
  const rel = path.relative(managedKeyDir(home), path.resolve(expandKeyPath(keyFile, home)));
  return rel !== '' && !rel.startsWith('..') && !path.isAbsolute(rel);
}

/** `ssh-keygen -Y sign` on a message file; writes `<messageFile>.sig`. */
export const signTestArgs = (keyFile: string, messageFile: string): string[] =>
  ['-Y', 'sign', '-f', keyFile, '-n', 'git', messageFile];

export const firstLine = (text: string): string => text.split(/\r?\n/).map(l => l.trim()).find(Boolean) ?? '';
```

```ts
'use strict';

import * as fs from 'node:fs';
import * as os from 'node:os';
import path from 'node:path';
import {
  firstLine, isManagedKey, keygenArgs, keyFileName, managedKeyDir, parseFingerprint, parsePublicKey, PublicKey,
  publicKeyFile, signTestArgs, uniqueKeyPath,
} from './sshKey';
import { expandKeyPath } from './gitPlan';
import { RunTool, runTool, TOOL_UNAVAILABLE, ToolResult } from './tool';

const KEYGEN = 'ssh-keygen';
const NOT_FOUND = 'ssh-keygen was not found on your PATH. Install the OpenSSH client (Windows: Settings → Optional features → OpenSSH Client).';
// Never let ssh-keygen fall back to an askpass helper: nothing here can answer it.
const NO_ASKPASS = { SSH_ASKPASS_REQUIRE: 'never' };

const notFound = (r: ToolResult): boolean => r.code === TOOL_UNAVAILABLE && /ENOENT/.test(r.stderr);

/** Creates a passphrase-less ed25519 key in `~/.ssh/null-accounts/` and returns its path. Never overwrites a key. */
export async function generateKey(
  input: { home: string; host: string; username: string; email: string },
  run: RunTool = runTool,
  exists: (file: string) => boolean = fs.existsSync,
): Promise<string> {
  const dir = managedKeyDir(input.home);
  fs.mkdirSync(dir, { recursive: true, mode: 0o700 });
  const file = uniqueKeyPath(dir, keyFileName(input.host, input.username), exists);
  const result = await run(KEYGEN, keygenArgs(file, input.email));
  if (notFound(result)) { throw new Error(NOT_FOUND); }
  if (result.code !== 0) { throw new Error(`ssh-keygen could not create the key: ${firstLine(result.stderr) || 'unknown error'}`); }
  return file;
}

/** The parsed `<keyFile>.pub`. `keyFile` is already expanded. */
export function readPublicKey(keyFile: string): PublicKey {
  const pub = publicKeyFile(keyFile);
  if (!fs.existsSync(pub)) {
    throw new Error(`There is no public key next to ${keyFile} (expected ${pub}).`);
  }
  return parsePublicKey(fs.readFileSync(pub, 'utf8'));
}

/** "SHA256:…" for the key, or `undefined` if it can't be read. Prefers the .pub so a passphrase never matters. */
export async function fingerprintOf(keyFile: string, run: RunTool = runTool): Promise<string | undefined> {
  const pub = publicKeyFile(keyFile);
  const result = await run(KEYGEN, ['-l', '-f', fs.existsSync(pub) ? pub : keyFile], { env: NO_ASKPASS });
  return result.code === 0 ? parseFingerprint(result.stdout) : undefined;
}

export interface SignCheck { ok: boolean; message: string }

/**
 * Whether git can sign with this key from inside the editor, without any prompt. A failed signature blocks the
 * commit, so signing is only ever switched on after this passes.
 */
export async function canSign(keyFile: string, run: RunTool = runTool): Promise<SignCheck> {
  // `-P ""` supplies an empty passphrase: a protected key fails here instead of waiting for a prompt nobody can answer.
  const unlocked = await run(KEYGEN, ['-y', '-P', '', '-f', keyFile], { env: NO_ASKPASS });
  if (notFound(unlocked)) { return { ok: false, message: NOT_FOUND }; }
  if (unlocked.code !== 0) {
    return {
      ok: false,
      message: `Git cannot sign with ${keyFile}: the key has a passphrase or cannot be read (${firstLine(unlocked.stderr) || 'no details'}). `
        + `Git cannot ask for a passphrase from inside the editor. Use a key Null IDE generated, or remove the passphrase with: ssh-keygen -p -f "${keyFile}"`,
    };
  }
  const dir = fs.mkdtempSync(path.join(os.tmpdir(), 'null-accounts-sign-'));
  try {
    const message = path.join(dir, 'message');
    fs.writeFileSync(message, 'null-accounts signing test\n');
    const signed = await run(KEYGEN, signTestArgs(keyFile, message), { env: NO_ASKPASS });
    if (signed.code === 0 && fs.existsSync(`${message}.sig`)) { return { ok: true, message: 'ok' }; }
    return {
      ok: false,
      message: `ssh-keygen could not sign with this key (${firstLine(signed.stderr) || 'no details'}). Signing needs OpenSSH 8.0 or newer.`,
    };
  } finally {
    fs.rmSync(dir, { recursive: true, force: true });
  }
}

/** Deletes a key pair Null IDE created. Anything outside `~/.ssh/null-accounts/` is refused, so a user's own key can never go. */
export function deleteManagedKey(keyFile: string, home: string): void {
  if (!isManagedKey(keyFile, home)) {
    throw new Error(`${keyFile} is not a key Null IDE created, so it will not be deleted.`);
  }
  const file = expandKeyPath(keyFile, home);
  fs.rmSync(file, { force: true });
  fs.rmSync(publicKeyFile(file), { force: true });
}
```

```ts
'use strict';

import { PublicKey } from './sshKey';
import { Account } from './types';

export interface HttpReply { status: number; body: unknown }

/** POST `body` as JSON. Resolves any HTTP response; rejects only on a network failure. */
export type PostJson = (url: string, headers: Record<string, string>, body: Record<string, unknown>) => Promise<HttpReply>;

/** The real `PostJson`. */
export const fetchPostJson: PostJson = async (url, headers, body) => {
  const res = await fetch(url, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Accept: 'application/json', 'User-Agent': 'null-ide', ...headers },
    body: JSON.stringify(body),
    redirect: 'error',
    signal: AbortSignal.timeout(15_000),
  });
  const text = await res.text();
  let parsed: unknown = text;
  try { parsed = text ? JSON.parse(text) : undefined; } catch { /* keep the raw text */ }
  return { status: res.status, body: parsed };
};

/** What a GitHub sign-in needs to add keys; asked for together, so the user approves once. GitLab's `api` scope is already in its OAuth flow. */
export const GITHUB_KEY_SCOPES = ['write:public_key', 'write:ssh_signing_key'];

export type UploadResult = { ok: true; already: boolean } | { ok: false; message: string };

/** Where to paste a public key by hand (accounts without a token). */
export function keySettingsUrl(account: Pick<Account, 'provider' | 'host'>): string {
  return account.provider === 'github'
    ? 'https://github.com/settings/ssh/new'
    : `https://${account.host}/-/user_settings/ssh_keys`;
}

const DUPLICATE = /already (in use|been taken|exists)/i;
// GitHub answers a key it already has with 422, GitLab with 400.
const isDuplicate = (reply: HttpReply): boolean =>
  (reply.status === 422 || reply.status === 400)
  && DUPLICATE.test(typeof reply.body === 'string' ? reply.body : JSON.stringify(reply.body ?? ''));

function serverSays(reply: HttpReply): string {
  const body = reply.body;
  const message = typeof body === 'string' ? body : (body as { message?: unknown } | undefined)?.message;
  const text = typeof message === 'string' ? message : message === undefined ? '' : JSON.stringify(message);
  return text.slice(0, 200);
}

function refusal(provider: string, reply: HttpReply, permissionHint: string): { ok: false; message: string } {
  if (reply.status === 401 || reply.status === 403) {
    return { ok: false, message: `${provider} refused (HTTP ${reply.status}): ${permissionHint}` };
  }
  const says = serverSays(reply);
  return { ok: false, message: `${provider} answered HTTP ${reply.status}${says ? `: ${says}` : '.'}` };
}

const GITHUB_HINT = 'the sign-in cannot add SSH keys. Allow "write:public_key" and "write:ssh_signing_key" when asked, or add the key by hand.';
const GITLAB_HINT = 'the token needs the "api" scope to add SSH keys (read_api is not enough), or add the key by hand.';

/**
 * Adds the public key to the account on its server for pushing and for signing. A key the server already has is a
 * success. The token only ever goes in an Authorization header to the account's own host.
 */
export async function uploadPublicKey(
  account: Pick<Account, 'provider' | 'host'>,
  token: string,
  key: PublicKey,
  title: string,
  post: PostJson = fetchPostJson,
): Promise<UploadResult> {
  const line = `${key.type} ${key.blob}`; // the comment is the user's email: no reason to send it
  const headers = { Authorization: `Bearer ${token}` };
  try {
    if (account.provider === 'github') {
      const auth = await post('https://api.github.com/user/keys', { ...headers, Accept: 'application/vnd.github+json' }, { title, key: line });
      const authAdded = auth.status === 201;
      if (!authAdded && !isDuplicate(auth)) { return refusal('GitHub', auth, GITHUB_HINT); }
      const signing = await post('https://api.github.com/user/ssh_signing_keys', { ...headers, Accept: 'application/vnd.github+json' }, { title, key: line });
      const signingAdded = signing.status === 201;
      if (!signingAdded && !isDuplicate(signing)) {
        const failed = refusal('GitHub', signing, GITHUB_HINT);
        return { ok: false, message: `The key was added for pushing, but not as a signing key. ${failed.message}` };
      }
      return { ok: true, already: !authAdded && !signingAdded };
    }
    const reply = await post(`https://${account.host}/api/v4/user/keys`, headers, { title, key: line, usage_type: 'auth_and_signing' });
    if (reply.status === 201) { return { ok: true, already: false }; }
    if (isDuplicate(reply)) { return { ok: true, already: true }; }
    return refusal('GitLab', reply, GITLAB_HINT);
  } catch {
    return { ok: false, message: `Could not reach ${account.host}.` };
  }
}
```

```ts
/** What to tell the user after a test: informational when it worked as expected, a warning otherwise. */
export function describeSshTest(
  account: Pick<Account, 'username' | 'host'>,
  check: SshCheck,
): { level: 'info' | 'warn'; text: string } {
  const who = `${account.username}@${account.host}`;
  if (!check.ok) { return { level: 'warn', text: `The SSH test for ${who} failed: ${check.message}` }; }
  if (check.user && check.user.toLowerCase() !== account.username.toLowerCase()) {
    return { level: 'warn', text: `${account.host} says this key belongs to ${check.user}, not ${account.username}.` };
  }
  return { level: 'info', text: `${check.message} Git in projects using ${who} will use this key.` };
}
```

```ts
'use strict';

import { GITHUB_KEY_SCOPES, keySettingsUrl, UploadResult } from '../keyUpload';
import { sshKeyFile } from '../gitPlan';
import { checkKeyPath } from '../sshAccount';
import { describeSshTest, SshCheck } from '../sshCheck';
import { isManagedKey, keyTitle, PublicKey } from '../sshKey';
import { SignCheck } from '../sshKeyOps';
import { Account, NewAccount } from '../types';

/** The few editor interactions the actions need, so they can be tested without a VS Code host. */
export interface KeyUi {
  confirm(message: string, detail: string, action: string): Promise<boolean>;
  info(message: string, ...actions: string[]): Promise<string | undefined>;
  warn(message: string, ...actions: string[]): Promise<string | undefined>;
  copy(text: string): Promise<void>;
  open(url: string): Promise<void>;
  pickKeyFile(): Promise<string | undefined>;
}

export interface KeyActionsDeps {
  accounts: {
    get(id: string): Account | undefined;
    update(id: string, patch: Partial<NewAccount>): Promise<Account>;
  };
  /** `api.getToken`; an interactive call may prompt the user to sign in or widen permissions. */
  getToken(account: Account, scopes: string[], options: { interactive: boolean }): Promise<string | undefined>;
  ui: KeyUi;
  home: string;
  hostname: string;
  now(): Date;
  exists(file: string): boolean;
  generate(input: { host: string; username: string; email: string }): Promise<string>;
  readPublicKey(keyFile: string): PublicKey;
  canSign(keyFile: string): Promise<SignCheck>;
  deleteManagedKey(keyFile: string): void;
  upload(account: Account, token: string, key: PublicKey, title: string): Promise<UploadResult>;
  checkSsh(host: string, keyFile: string): Promise<SshCheck>;
}

const who = (a: Pick<Account, 'username' | 'host'>): string => `${a.username}@${a.host}`;

/**
 * What the Accounts panel's key buttons do. Each method throws an Error with a message fit to show the user;
 * notifications that need no answer are fired without waiting (a toast resolves only when dismissed).
 * Changing a key goes through `accounts.update`, so the git wiring follows on its own.
 */
export class KeyActions {
  constructor(private readonly d: KeyActionsDeps) {}

  /** Creates a new key for the account and offers to put it on the server. */
  async generate(id: string): Promise<void> {
    const account = this.need(id);
    if (account.sshKeyPath) {
      const go = await this.d.ui.confirm(
        `Replace the SSH key of ${who(account)}?`,
        'The current key file stays on disk. Commit signing is switched off until you turn it on again for the new key.',
        'Generate',
      );
      if (!go) { return; }
    }
    const file = await this.d.generate({ host: account.host, username: account.username, email: account.email });
    await this.setKey(account, file);
    await this.afterNewKey(id);
  }

  /** The next step after a key was created: the server has to learn its public half. */
  async afterNewKey(id: string): Promise<void> {
    const account = this.need(id);
    const label = account.authMethod === 'ssh' ? `Copy key and open ${account.host}` : `Upload to ${account.host}`;
    const choice = await this.d.ui.info(
      `Created an SSH key for ${who(account)}. ${account.host} has to know its public key before it can be used.`,
      label,
      'Copy public key',
    );
    if (choice === label) { await this.upload(id); } else if (choice === 'Copy public key') { await this.copyPublic(id); }
  }

  /** Uses a key file the user already has. */
  async attach(id: string): Promise<void> {
    const account = this.need(id);
    const picked = await this.d.ui.pickKeyFile();
    if (!picked) { return; }
    const problem = checkKeyPath(picked, this.d.home, this.d.exists);
    if (problem) { throw new Error(problem); }
    await this.setKey(account, picked);
    await this.test(id);
  }

  async copyPublic(id: string): Promise<void> {
    const account = this.need(id);
    await this.d.ui.copy(this.publicKey(account).line);
    void this.d.ui.info(`Copied the public key of ${who(account)}.`);
  }

  /** Puts the public key on the server for pushing and signing; for an account without a token, copies it and opens the page to paste it into. */
  async upload(id: string): Promise<void> {
    const account = this.need(id);
    const key = this.publicKey(account);
    if (account.authMethod === 'ssh') {
      await this.d.ui.copy(key.line);
      await this.d.ui.open(keySettingsUrl(account));
      const twice = account.provider === 'github' ? ' Add it once as an Authentication key and once as a Signing key.' : '';
      void this.d.ui.info(`Public key copied. Paste it on the page that just opened.${twice} Then press Test.`);
      return;
    }
    const scopes = account.provider === 'github' ? GITHUB_KEY_SCOPES : [];
    const token = await this.d.getToken(account, scopes, { interactive: true });
    if (!token) {
      throw new Error(`There is no sign-in for ${who(account)}. Re-authenticate the account and try again, or use Copy public key and add the key by hand.`);
    }
    const result = await this.d.upload(account, token, key, keyTitle(this.d.hostname, this.d.now()));
    if (!result.ok) { throw new Error(result.message); }
    void this.d.ui.info(result.already ? `${account.host} already had this key.` : `Added the key to ${who(account)} for pushing and signing.`);
    await this.test(id);
  }

  /** `ssh -T` with only this key. */
  async test(id: string): Promise<void> {
    const account = this.need(id);
    const check = await this.d.checkSsh(account.host, this.keyFile(account));
    const outcome = describeSshTest(account, check);
    void (outcome.level === 'warn' ? this.d.ui.warn(outcome.text) : this.d.ui.info(outcome.text));
  }

  /** Signing is only switched on once the key is known to sign without any prompt: a failed signature blocks the commit. */
  async setSigning(id: string, on: boolean): Promise<void> {
    const account = this.need(id);
    if (!on) {
      await this.d.accounts.update(id, { signCommits: undefined });
      return;
    }
    const keyFile = this.keyFile(account);
    if (!this.d.exists(keyFile)) { throw new Error(`The key file ${keyFile} was not found.`); }
    const check = await this.d.canSign(keyFile);
    if (!check.ok) { throw new Error(check.message); }
    await this.d.accounts.update(id, { signCommits: true });
    void this.d.ui.info(
      `Commits in projects using ${who(account)} will be signed. They show as Verified once the public key is on ${account.host} as a signing key (Upload does both).`,
    );
  }

  /** Deletes a key Null IDE created; for a key the user brought, only stops using it. */
  async removeKey(id: string): Promise<void> {
    const account = this.need(id);
    if (account.authMethod === 'ssh') {
      throw new Error('An SSH-only account needs its key. Generate or choose another key, or remove the account.');
    }
    const keyFile = this.keyFile(account);
    const managed = isManagedKey(keyFile, this.d.home);
    const go = await this.d.ui.confirm(
      managed ? `Delete the SSH key of ${who(account)}?` : `Stop using the SSH key of ${who(account)}?`,
      managed
        ? `The key files are deleted from this computer. ${account.host} keeps trusting the public key until you remove it in your SSH key settings there.`
        : 'The key file stays where it is.',
      managed ? 'Delete' : 'Stop using',
    );
    if (!go) { return; }
    // Config first, so the repos let go of the key before its file disappears.
    await this.d.accounts.update(id, { sshKeyPath: undefined, signCommits: undefined });
    if (managed) { this.d.deleteManagedKey(keyFile); }
  }

  /** A new key is not a signing key on the server yet, so signing starts off. */
  private async setKey(account: Account, file: string): Promise<void> {
    await this.d.accounts.update(account.id, { sshKeyPath: file, signCommits: undefined });
  }

  private need(id: string): Account {
    const account = this.d.accounts.get(id);
    if (!account) { throw new Error('That account no longer exists.'); }
    return account;
  }

  private keyFile(account: Account): string {
    const file = sshKeyFile(account, this.d.home);
    if (!file) { throw new Error(`${who(account)} has no SSH key yet.`); }
    return file;
  }

  private publicKey(account: Account): PublicKey {
    return this.d.readPublicKey(this.keyFile(account));
  }
}
```

```ts
'use strict';

import { sshKeyFile } from '../gitPlan';
import { isManagedKey } from '../sshKey';
import { Account } from '../types';

/** What the panel shows about an account's key. */
export interface KeyRow {
  /** As stored on the account. */
  path: string;
  exists: boolean;
  /** Created by Null IDE (inside ~/.ssh/null-accounts): the only keys the panel can delete. */
  managed: boolean;
  fingerprint?: string;
  signCommits: boolean;
  /** An SSH-only account cannot lose its key. */
  removable: boolean;
}

export interface KeyInfoDeps {
  home: string;
  exists(file: string): boolean;
  fingerprintOf(keyFile: string): Promise<string | undefined>;
}

/** One row per account that has a key. Never rejects: an unreadable key just has no fingerprint. */
export async function describeKeys(accounts: readonly Account[], deps: KeyInfoDeps): Promise<Map<string, KeyRow>> {
  const rows = new Map<string, KeyRow>();
  await Promise.all(accounts.filter(a => a.sshKeyPath).map(async account => {
    const keyFile = sshKeyFile(account, deps.home);
    const exists = deps.exists(keyFile);
    const fingerprint = exists ? await deps.fingerprintOf(keyFile).catch(() => undefined) : undefined;
    rows.set(account.id, {
      path: account.sshKeyPath!,
      exists,
      managed: isManagedKey(keyFile, deps.home),
      ...(fingerprint ? { fingerprint } : {}),
      signCommits: account.signCommits === true,
      removable: account.authMethod !== 'ssh',
    });
  }));
  // Promise.all settles in completion order; keep the accounts' own order.
  return new Map(accounts.filter(a => rows.has(a.id)).map(a => [a.id, rows.get(a.id)!]));
}
```
