# null-sync

Cross-device sync (issue #23) of `settings.json`, `keybindings.json` and snippets and the installed-extension list with no server of our own: one secret GitHub Gist per user, reached through null-accounts (`getToken(account, ['gist'], …)`, github.com accounts only) and **encrypted on the device** (AES-256-GCM, scrypt key from a passphrase of at least 12 characters kept in `SecretStorage`; a secret Gist is only unlisted, so it holds ciphertext plus a plaintext `manifest.json` with the KDF parameters). The passphrase cannot be recovered: forgetting it means Stop Syncing and starting a new store. `extensionKind: ["ui"]`, off by default (`null-sync.enabled`), not run in Safe Mode (publisher `null` built-ins are disabled). Pure, injectable modules: `cryptoBox`; `syncPlan` (`planFile(local, remote, base, deletable)`, where `base` is the pair `{ local, remote }` recorded at the last sync because a pulled `settings.json` is not byte-identical to the remote text); `settingsFilter` (`jsonc-parser`, the only runtime dependency; removes `null-sync.excludedSettings` keys — paths, terminal profiles, proxy, anything matching `*token*`/`*secret*`/`*password*`/`*apiKey*`/`*credential*` — before hashing and uploading, and puts this device's values back on pull); `gistStore` (+ `gistHttp.ts`, the only `fetch`); `localFiles` (every name through `isSyncableFile`, atomic writes, backups of the losing version under `globalStorage/null-sync/backups`, last 10 per file); `lock` (cross-window lock file); `enable`; `syncEngine` (`run` / `resolve` / `restore` / `stop`). Only `prompts.ts`, `commands.ts`, `extensionHost.ts` and `extension.ts` import `vscode`. The `activity` category (default **off**, consent modal) has no files in the three-way engine: `syncEngine.syncActivity(exchange)` hands null-activity the `activity__*` Gist files and uploads what it returns (see null-activity). Whole-file three-way sync: one side changed wins; both changed is a conflict that is never auto-resolved; a missing `settings.json`/`keybindings.json` never deletes the remote copy, a deleted snippet does; a file open with unsaved edits is skipped and retried. `extensionSet` merges the installed-extension IDs by set arithmetic (never a conflict); `extensionHost.ts` reads them from `~/<dataFolderName>/extensions/extensions.json` so disabled extensions count, and an unreadable file skips the extension sync instead of reading as 'all uninstalled'. Only interactive runs install; removals are only reported (`pendingRemovals`) until `uninstallRemoved(id)`. Background runs (startup + 10 s, 30 s after a change, every 10 min) never prompt. **No UI:** `activate` returns `NullSyncApi` (`getStatus`, `onDidChangeStatus`, `syncNow`, `resolveConflict`, `uninstallRemoved`) and the `null.sync.*` commands include `null.sync.showStatus`; the Null workspace rework will build the Sync screen on that contract. Design `docs/specs/null-sync-design.md`; plan `docs/plans/null-sync.md`. Integration spec: `npm run test:integration` (via `/verify-local null-sync`).
