# null-markdown

Enhanced markdown preview (GFM, Mermaid, KaTeX, GitHub alerts) on `onLanguage:markdown`, plus the **Markdown Editor** (issue #114): a live-preview `CustomTextEditorProvider` (`null-markdown.editor`; syntax markers hide except around the caret) that is the default view of `.md` files, with a single title-bar button toggling to the plain text editor (Source). `editorProvider.js` is a thin relay over the `TextDocument` (source of truth): the webview mirrors LF text, sends debounced edits with a `baseVersion` that the host applies as one `WorkspaceEdit` and acks, and any host change returns as a full `doc` that the webview diffs in; `syncState.js` (pure) holds the offset/EOL mapping and version rules. Undo/redo is the workbench's (no CodeMirror history). The webview is `webview/editor/*.mjs` (CodeMirror 6 + `@lezer/markdown`, dev dependencies) bundled by `npm run build` (esbuild) into the tracked `lib/editor.js`; `lib/editor.css` is hand-written. `specs.mjs` is the pure decoration plan (tree + selection in, specs out); tables, Mermaid, `$$` math, alerts, HTML and images render as widgets through the host's `createMd()` + `processAlerts()` (`renderBlock`/`rendered` messages). The Editor page does not load KaTeX or Mermaid up front (`lazyLibs` in `pages.js`; `renderer.mjs` loads each from `window.nullLibs` when a block needs it), while the Preview page still loads them eagerly. Typography (font, line height) must go through `EditorView.theme` in `main.mjs`: a plain `.cm-scroller` rule in `editor.css` loses to CodeMirror's base theme. For the same reason line-level rules in `editor.css` (headings, quotes, code blocks, `.cm-li`) are prefixed `#editor`: the base theme's `.cm-line { padding: 0 2px 0 6px }` out-ranks a single class. Widgets reset `white-space` to `normal` because CodeMirror's `pre-wrap` is inherited into them. Open timings are logged to the "Null Markdown" Output channel. `node_modules` (markdown-it, KaTeX, Mermaid, highlight.js) come from `npm ci --prefix` in CI and are not synced by `sync-local.ps1`; it copies `lib/` and the host files. Design: `docs/specs/null-markdown-editor-design.md`; plan: `docs/plans/null-markdown-editor.md`.
